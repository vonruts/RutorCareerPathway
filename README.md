# Infrastructure Atlas — Von Rainier Rutor

Responsive System Administrator Career Pathways portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser or use VS Code Live Server.
3. No build step, package installation, database, or login system is required.

## Included
- `index.html` — complete website structure, CSS styling, and JavaScript interactions.
- Responsive desktop/mobile navigation.
- Three interactive career stages with responsibilities and skills.
- Six interactive skills with explanations.
- Comparison of three related IT roles.
- Tools and technologies section.
- Interactive practice checklist saved in the current browser.
- About section for Von Rainier Rutor.

## Design
Infrastructure Atlas uses a deep-plum, acid-lime, coral, and warm-ivory palette with an orbital infrastructure illustration, editorial typography, career route rail, open skills index, and role comparison rows instead of repetitive card grids.

## Personalization
The About section includes a general student introduction and career goal. Edit the text in `index.html` if your actual introduction or goals differ.
